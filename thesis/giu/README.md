# GIU template version of the thesis

Built on 23 November 2026 from `../main.tex` and the supervisor's GIU Bachelor Thesis template.
Main file: `main.tex` (the GIU template calls it bachelor.tex) (compile with pdfLaTeX + BibTeX; Overleaf does this automatically).

- `sections/`: the seven chapters (Introduction, Background, Related Work, Methodology, Implementation,
  Results, Conclusion and Future Work). Every paragraph of the old `main.tex` was moved, not rewritten;
  each file starts with `% NOTE` comments saying what still needs work.
- `appendix.tex` / `appendix_content.tex`: lists, requirements, screenshots, planning records.
- `references.bib`: the reference records, rendered in IEEE style (`ieeetr`).
- Abstract, Acknowledgments and the Conclusion chapter are placeholders to be written.

Much of the moved text was drafted with AI assistance. The supervisor runs AI checks, so rewrite it in
your own words before submission. The old single-file `../main.tex` is kept unchanged for reference.
