**Current workflow (23 November 2026):** the thesis source is `overleaf/`, laid out exactly like the supervisor's GIU Bachelor Thesis template (main file `bachelor.tex`, `title_page.tex`, `abstract.tex`, `acknowledgments.tex`, `appendix.tex`, `sections/`, `references.bib`, `figures/`); this is the folder that goes to Overleaf (`overleaf.zip`). `bash thesis/build.sh` builds `thesis-draft.pdf` from it and regenerates `main.tex`, a single-file copy of the whole thesis (do not edit `main.tex` directly). A git pre-commit hook (`scripts/git-hooks/pre-commit`, enabled with `git config core.hooksPath scripts/git-hooks`) rebuilds and commits the PDF and `main.tex` whenever `overleaf/` changes, and refuses commits that edit `main.tex` by hand. Edits made in Overleaf must be copied back into `overleaf/`.
